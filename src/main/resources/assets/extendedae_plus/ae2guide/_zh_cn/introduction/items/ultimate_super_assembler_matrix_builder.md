# 终极超级装配矩阵搭建器

<ItemImage id="extendedae_plus:ultimate_super_assembler_matrix_builder" scale="4" />

**终极超级装配矩阵搭建器**用于放置并立即成型固定布局的终极超级装配矩阵。选定起点后会显示锁定的结构预览；预览时按住 **Ctrl** 可查看各个结构部件。

## 搭建流程

1. 右键方块的一个面，将相邻的空气方块设为搭建起点。
2. 查看结构预览；潜行右键另一个方块可重新选择起点。
3. 再次右键任意方块，即在已选起点执行搭建。
4. 潜行右键空气可取消已选起点，不会执行搭建。

工具会在放置前检查全部必需方块位置，绝不会覆盖已有方块。若存在障碍物，搭建失败且不会改变世界。

## 创造与生存模式

创造模式下无需消耗材料，可直接放置完整结构。

生存模式下，请先潜行右键一个 **ME 接口**以绑定材料网络。搭建前工具会模拟检查该网络的全部材料；材料齐全时才会扣除材料并放置完整结构。材料不足时，聊天栏会列出缺失物品及数量，且不会消耗任何材料。
